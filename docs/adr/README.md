# Architecture decision records

ADRs capture decisions that outlive an implementation packet. Use one when changing a durable format, object/link topology, persistence boundary, security assumption, dependency policy, or release contract.

Copy [0000-adr-template.md](0000-adr-template.md), assign the next available number, and use a short kebab-case title. Keep the record append-only after acceptance: supersede it with a new ADR rather than rewriting history. An ADR may be proposed without approval, but the status and owner must be explicit.
